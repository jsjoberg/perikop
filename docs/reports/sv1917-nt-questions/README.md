# Sparade läsningsfrågor: övriga NT

Användaren är borta från boken; **ingen åtgärd behövs nu**. Här samlas frågor från Apostlagärningarna till Uppenbarelseboken. Evangeliernas [separata fotolista](../sv1917-gospel-questions/photo-checklist.md) behålls.

| Bunt | Text | Frågor | Hela verser att fotografera senare |
| --- | --- | ---: | --- |
| [NT 1](batch-1.md) | Apostlagärningarna 1–12 | 5, V123–V127 | 2:2; 4:1, 21; 5:1, 13 |

Alla fem frågor har full korpusvers, läsbart originalutsnitt, full sidlänk och exakta TIFF-/utsnittshashar. Foton av hela verserna räcker; Codex tolkar dem. Frågorna är inte fastställda fel och deras kapitel räknas inte som verifierade. [Arbetsstatus och nästa kapitel](../sv1917-rest-nt.md).
