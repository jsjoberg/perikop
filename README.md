# Perikop

An offline Orthodox lectionary reader with a Swedish interface, Scripture in Swedish, Greek, and English, and read-aloud in all three languages.
It is an early prototype. The shared Linux ARM64 download targets Raspberry Pi 3, 4 and 5 on 64-bit Raspberry Pi OS Trixie with a desktop; see the [requirements and validation status](docs/using-perikop.md#raspberry-pi-3-4-and-5).
